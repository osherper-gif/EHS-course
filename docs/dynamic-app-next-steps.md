## מטרת הגרסה הדינמית

להכין בסיס הדרגתי לאתר קורס דינמי, שבו תכנים, שיעורים, שאלות, התקדמות תלמידים וכלי ניהול יוכלו להיטען ממודל נתונים מסודר במקום להיות מנוהלים רק כ־HTML סטטי.

העבודה תתבצע בשלבים קטנים, תחילה ב־Local/Staging בלבד, בלי פגיעה באתר הקורס הקיים ובלי מעבר ל־production ללא אישור מפורש.

## אסור לשנות בלי אישור מפורש

- Production או כל deploy ל־production.
- `firebase.json` או הגדרות deploy.
- `.firebaserc` או בחירת פרויקט Firebase.
- `firestore.rules`.
- קבצי Auth, כולל `js/auth.js`.
- `js/firebase-config.js`.
- כל שינוי שמחבר כתיבה ל־Firestore לפני אפיון והרשאה.
- כל שינוי שמחליף את `index.html` הראשי או משנה את האתר הפעיל ללא אישור.

## תוכנית עבודה מוצעת

1. אפיון data model
   - Lesson
   - Topic
   - Question
   - UserProgress
   - CourseModule
   - LegalReference
   - Asset/Resource

2. תכנון collections ל־Firestore
   - תכנון בלבד בשלב ראשון.
   - אין שינוי rules ללא diff ואישור.
   - אין כתיבה לענן עד אישור Cloud Mode.

3. Content Manager
   - מסך ניהול מקומי או staging-only לניהול שיעורים ושאלות.
   - הפרדה בין תוכן לימודי, שאלות, חוקים, תקנים וכלי שטח.

4. טעינת שיעורים דינמית
   - יצירת renderer שמסוגל להציג שיעור ממבנה נתונים.
   - שמירה על fallback לדפים סטטיים קיימים.

5. ניהול שאלות דינמי
   - שיוך שאלות לפי lesson/topic/difficulty/tags.
   - שמירה על התאמה ל־quizzes, exam questions ואתגר הבטיחות.

6. progress תלמיד
   - מודל התקדמות מקומי תחילה.
   - Cloud Mode רק לאחר אפיון פרטיות והרשאות.

7. Staging בלבד
   - כל בדיקה ראשונה תתבצע מקומית וב־staging.
   - אין production ללא אישור מנהל האתר.

8. Production רק באישור
   - מעבר ל־production יבוצע רק אחרי UAT, בדיקות אבטחה, בדיקות קישורים, ובדיקת אי־פגיעה באתר הקורס הקיים.

## בדיקות בסיס לפני התחלת פיתוח

- לוודא שהענף נקי.
- לוודא שאין שינויי EHS או deploy config בענף הדינמי ללא החלטה נפרדת.
- להריץ בדיקות קישורים לפני כל deploy ל־staging.
- לוודא שאין שינוי ב־Firestore/Auth לפני אישור.

## הערת זהירות

הגרסה הדינמית צריכה להתקדם במקביל לאתר הקיים, לא להחליף אותו בבת אחת. כל מודול דינמי צריך להיבנות עם fallback ויכולת בדיקה מבודדת.
