# קורס ממונה בטיחות - אתר למידה סטטי

אתר HTML מקומי עבור קורס "ממונה בטיחות" של באר הדרכות.

## מבנה

- `index.html` - דף בית וחיפוש
- `pages/` - תוכנית לימוד, עמודי מפגשים, מילון, חוקים, תרגול ועוזר מקומי
- `data/course-data.js` - כל נתוני הקורס המקומיים
- `js/` - חיפוש, עוזר מקומי, בוחנים, אחסון והפעלת האתר
- `css/styles.css` - עיצוב RTL, רספונסיבי והדפסה

## שימוש

פותחים את `index.html` בדפדפן. אין צורך בשרת, Backend, ענן או API.

## מצב תוכן

המפגש "יסודות תורת הבטיחות" מולא מתוך קובץ ה-HTML הקיים. שאר המפגשים נבנו כשלד לפי קובצי המקור ומסומנים "נדרש השלמת תוכן" עד חילוץ ואימות תוכן מלא מה-PDF.

## הערה משפטית
