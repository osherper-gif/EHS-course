# אתר לימודי בתחום הבטיחות

אתר סטטי ללמידה, תרגול, סיכום והכנה למבחן ממונה בטיחות.

## מה קיים באתר

- שיעורים מסודרים לפי מפגשי לימוד.
- מאגר שאלות מבחן לפי שיעור ולפי נושא.
- תרגול, מבחנים, ציונים והסברים לתשובות.
- כלים מקצועיים: חוקים, תקנים, רשימות תיוג ופורמטים.
- מנגנוני התחברות, הרשאות אדמין, דיווח תקלה וניהול גרסאות.

## שימוש

האתר מיועד לפריסה סטטית ב-Firebase Hosting. אין Backend פרטי, אין React, אין Vite ואין API חיצוני לתוכן הלימודי.

## הערה מקצועית

המידע נועד ללמידה והעשרה בלבד. יש לאמת כל דרישה מול נוסח החוק, התקנה או התקן העדכני וגורם מוסמך.
