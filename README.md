# קורס ממונה בטיחות - אתר למידה סטטי

אתר HTML מקומי עבור קורס "ממונה בטיחות" של הקורס.

## מה עודכן

- כל מפגשי הקורס מולאו בתוכן לימודי עשיר.
- המפגש "יסודות תורת הבטיחות" מבוסס על קובצי HTML/PDF/DOCX שניתנו לחילוץ.
- קובצי PDF נוספים זוהו כסרוקים מבחינת חילוץ טקסט, ולכן נוספה בכל עמוד הערה עדינה על עיבוד/סיכום של חומר סרוק.
- הרחבות חיצוניות או הרחבות AI מסומנות בכותרות מפורשות.
- מאגר הידע המקומי, המילון, החוקים והבוחנים הורחבו.

## שימוש

פותחים את `index.html` בדפדפן. אין Backend, אין React, אין Vite, אין שרת ואין API חיצוני.

## הערה משפטית

יש לאמת מול נוסח החוק/התקנה העדכני והמרצה.
